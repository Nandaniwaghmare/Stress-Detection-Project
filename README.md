# Stress Detection System using CNN and Tkinter

This is an academic capstone project focused on detecting human stress levels using Convolutional Neural Networks (CNN) and a Python-based Graphical User Interface (GUI) built with Tkinter.

## 🚀 Features
* **User Authentication:** Secure Login and Registration system backed by an SQLite database.
* **Stress Analysis:** Real-time stress detection and analysis using deep learning (CNN model).
* **Interactive GUI:** User-friendly desktop application interface designed using Python Tkinter and PIL.
* **Yoga & Relaxation Suggestions:** Recommends specific yoga poses and relaxation resources based on detected stress levels.

## 🛠️ Technologies Used
* **Programming Language:** Python
* **Deep Learning Framework:** TensorFlow / Keras (CNN)
* **GUI Framework:** Tkinter, PIL (Pillow)
* **Database:** SQLite
* **Version Control:** Git & GitHub

## 📂 Project Structure
* `GUI_Main.py` - Main dashboard / landing page interface.
* `Login.py` & `Registration.py` - Manages user authentication and database operations.
* `stress_Analysis.py` - Core script for running stress evaluation.
* `emotion_1_updated.py` - Real-time emotion/stress classification via webcam and CNN model.
* `Train.py` - Model training script.
* `yoga.py` - Provides yoga pose recommendations for stress relief.
